Install the Pallet GitHub App

We'll send you to GitHub to finish. Come back here when you're done.

  1. Pick the GitHub organization or personal account that owns the code.
  2. Choose all repositories, or only the ones Pallet should see.
  3. GitHub sends you back here and the account shows up in the list.
Pallet asks for read access to code and metadata, and permission to report build status on commits.

Remove amani-otieno?

Kilima Labs will stop seeing this account's repositories. No apps use it, so nothing stops building. The Pallet app stays installed on GitHub until you uninstall it there.

Remove kilima-labs?

These apps build from its repositories. Removing it disconnects them, and pushes stop building until each one is linked again.
